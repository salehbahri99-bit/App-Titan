# كيف رُكِّبت هذه المهارة هنا

المصدر: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (رخصة MIT)
الإصدار المنسوخ: `2.13.0` (حزمة `ui-ux-pro-max` وحدها من بين سبع مهارات).

أمر `/plugin` غير متاح في جلسات الويب، فرُكِّبت **كمهارة مشروع** لا كإضافة:
المجلّد داخل المستودع، فتعمل لكل من يفتح المشروع بلا تركيب على جهازه.

**التعديل الوحيد على الأصل**: أحد عشر مساراً في `SKILL.md` كانت تبدأ بـ
`${CLAUDE_PLUGIN_ROOT}` — وهو متغيّر لا يُضبط إلا بتركيب الإضافة — فصارت
مساراتٍ نسبية من جذر المستودع:

```
python ".claude/skills/ui-ux-pro-max/scripts/search.py" "<query>" --domain <domain>
```

لا شيء غير ذلك تغيّر: البيانات والسكربتات والمراجع كما نشرها صاحبها.

## للتحديث لاحقاً

```bash
git clone --depth 1 https://github.com/nextlevelbuilder/ui-ux-pro-max-skill /tmp/uiux
rm -rf .claude/skills/ui-ux-pro-max
cp -r /tmp/uiux/.claude/skills/ui-ux-pro-max .claude/skills/
sed -i 's#\${CLAUDE_PLUGIN_ROOT}/#.claude/skills/ui-ux-pro-max/#g' .claude/skills/ui-ux-pro-max/SKILL.md
```

## تحقّق سريع

```bash
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "accessibility contrast" --domain ux
```
