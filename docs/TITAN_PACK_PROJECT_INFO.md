# TITAN PACK — Claude Code Project Information

## Project Identity

**Project Name:** Titan Pack  
**Arabic Name:** تيتان باك

Titan Pack is a professional packaging design and production company website. The website must present the company as a specialized team of five experts covering the complete packaging workflow from concept to production.

---

## Core Vision

Titan Pack is not just a static website.

The project must be built as:

**Premium Website + CMS + Visual Editor + Admin Dashboard + Design System**

The owner must be able to manage the website completely without editing source code.

---

The company is presented as a specialized team of five experts:

# Development Rules for Claude Code

Before coding:

1. Inspect the existing project.
2. Inspect package.json.
3. Identify the framework.
4. Inspect database and backend.
5. Inspect authentication.
6. Inspect existing components.
7. Inspect existing assets.
8. Identify what already exists.
9. Identify missing functionality.
10. Create a practical implementation plan.

If an existing application is present, do not rebuild it unnecessarily.

Reuse good existing architecture.

Do not delete existing data without confirmation.

Do not introduce unnecessary dependencies.

# Final Instruction to Claude Code

Start by analyzing the current project.

Do not immediately write code.

Then create an implementation plan and execute it phase by phase.
