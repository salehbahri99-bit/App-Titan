# Titan Pack — النموذج التفاعلي

نموذج تفاعلي لموقع **تيتان باك** ولوحة التحكم التي تديره. الهدف تجربة المنصة كاملة قبل بنائها
على الخادم: التحرير، المسودة، المعاينة، النشر، والإصدارات. المرجع هو `docs/TITAN_PACK_PROJECT_INFO.md`.

| الملف | ما هو |
|---|---|
| `index.html` | الموقع العام (يُبنى من `src/`) |
| `admin.html` | لوحة التحكم (يُبنى من `src/`) |
| `build.py` | يجمع كل صفحة في ملف واحد (CSS و JS والشعارات مضمّنة) |

## التشغيل

```bash
python prototype/build.py          # بعد أي تعديل في src/
cd prototype && python -m http.server 8000
# الموقع:        http://localhost:8000/index.html
# لوحة التحكم:   http://localhost:8000/admin.html
```

يُفضَّل التشغيل عبر خادم محلي (وليس بفتح الملف مباشرة) حتى تتشارك الصفحتان التخزين وتعمل المعاينة
المباشرة بين اللوحة والموقع.

فيديوهات خلفيات الأقسام في `prototype/media/`: خمسة مقاطع (رسم الفرد، علبة تدور، شبكة CMYK،
الكرتون المموج، فرخ المطبعة) بصيغتي MP4 و WEBM مع صورة غلاف JPG لكل مقطع. المتصفح يختار الصيغة
المدعومة تلقائياً.

## بنية `src/`

```text
src/
  tokens.css        ألوان وخطوط الهوية (مشتركة بين الموقع واللوحة، فاتح + داكن)
  shared.js         نموذج المحتوى CONTENT (عربي/إنجليزي)، المشاريع، الأيقونات، مولّد مجسمات العلب
  cms.js            طبقة CMS: المسودة / المعاينة / النشر، دمج المحتوى، محرّك الثيم
  shell.html        هيكل الموقع       ← index.html
  styles.css        تنسيق الموقع
  app.js            عرض الموقع + ربطه بطبقة CMS
  admin/shell.html  هيكل اللوحة       ← admin.html
  admin/admin.css   تنسيق اللوحة
  admin/core.js     الحالة، الصلاحيات، النشر، الإصدارات، الوسائط، مكوّنات الواجهة
  admin/pages.js    صفحات اللوحة الخمس عشرة
  admin/assistant.js المساعد الذكي
```

الموقع واللوحة يقرآن **نفس** نموذج المحتوى من `shared.js`، فلا يوجد نص أو مشروع مكتوب مرتين.

## مسار النشر

```text
تعديل ← حفظ مسودة ← معاينة ← نشر
```

| الحالة | المفتاح (في النموذج) | من يقرأه |
|---|---|---|
| نسخة العمل | `tp-cms-work` | المعاينة المباشرة داخل اللوحة (`index.html?preview=work`) |
| المسودة | `tp-cms-draft` | زر «معاينة» (`index.html?preview=draft`) مع شريط «معاينة المسودة» |
| المنشور | `tp-cms-live` | الموقع العام `index.html` |
| الإصدارات | `tp-cms-versions` | `index.html?preview=v3` واستعادة أي إصدار كمسودة |

كل نشر يحفظ نسخة كاملة مع: رقم الإصدار، التاريخ، المستخدم، ملخص التغييرات. الاستعادة لا تغيّر
الموقع مباشرة — تُحمَّل كمسودة ثم تُنشر.

**عقد البيانات** (شكل الـ payload الذي سيصبح استجابة الـ API):
`content.{ar,en}` · `cats` · `projects[]` · `sections[]` · `services[]` · `team[]` · `tst[]` ·
`videos[]` · `baMedia[]` · `bg` · `theme` · `seo` · `settings`. التعريف الكامل وقيمه الافتراضية في
`TPCMS.BASE` داخل `src/cms.js`.

## صفحات لوحة التحكم

| الصفحة | ما تتيحه |
|---|---|
| لوحة التحكم | حالة النشر والتغييرات المعلّقة، مؤشرات، الطلبات الواردة، **قائمة اختبار القبول (20 بنداً)**، آخر النشاط |
| الصفحات | صفحات الموقع ولغاتها وحالتها |
| الأقسام | منشئ بصري: سحب لإعادة الترتيب، إظهار/إخفاء، تكرار، حذف، إضافة 16 نوعاً، محرر لكل قسم مع معاينة مباشرة |
| المشاريع | شبكة قابلة للسحب، فلاتر، مشاريع مميزة، تصنيفات ديناميكية، محرر كامل (محتوى، وسائط، معرض، قبل/بعد، فرد، إنتاج، مجسم مولّد حي، SEO) |
| الخدمات / الفريق / الآراء | إضافة، تعديل، ترتيب، إخفاء، حذف — النصوص لكل لغة والترتيب مشترك |
| الوسائط | مجلدات، بحث، فلترة، رفع بالسحب، تحويل الصور تلقائياً إلى WebP، إعادة تسمية، نقل، استبدال، حذف مع تحذير «مستخدم في…» |
| الهوية والثيم | 11 لوناً، خطوط العناوين والنص، الحجم والارتفاع والوزن، الاستدارة، شكل الأزرار، عرض الحاوية، الحركة، ثيمات جاهزة، فحص التباين WCAG — مع معاينة مباشرة (سطح مكتب / لوحي / جوال) |
| القائمة والتذييل | روابط القائمة ووجهاتها وترتيبها، زر CTA، أعمدة التذييل ونصوصه |
| SEO | العنوان والوصف لكل لغة مع معاينة Google، صورة OG، Canonical، robots، sitemap.xml و JSON-LD مولّدان |
| النماذج | صندوق الطلبات الواردة من نموذج «لنبدأ مشروعك» مع المرفقات والحالة، وإعدادات النموذج |
| المستخدمون | المستخدمون والأدوار ومصفوفة الصلاحيات، دعوة مستخدم |
| الإعدادات | اسم العلامة، اللغات، بيانات التواصل، تصدير/استيراد JSON، إعادة الضبط |
| الإصدارات | السجل الكامل، معاينة أي إصدار، مقارنته بالمسودة، استعادته |

**الأدوار:** المالك (كل شيء) · المدير (المحتوى والنشر والثيم) · المحرر (تعديل وحفظ مسودة، بلا نشر) ·
المشاهد (قراءة فقط). يمكن تبديل الدور من أيقونة الدرع أسفل القائمة الجانبية لتجربة الصلاحيات.

**المساعد الذكي** (زر ✳ في الشريط العلوي) يفهم أمثلة ملف المشروع: «اجعل الموقع أكثر فخامة»،
«غيّر اللون الأساسي إلى الأسود»، «أضف هذا المشروع إلى المعرض»، «اكتب وصفاً احترافياً لهذا المشروع»،
«أنشئ قسم جديد للخدمات»، «أخفِ قسم الفيديو». التعديلات الصغيرة تُنفَّذ مع زر «تراجع»، والكبيرة
(ثيم كامل، قسم جديد) تنتظر التأكيد. كل ما يفعله يبقى في المسودة.

## وضعا التشغيل

`src/config.js` يحدد الوضع:

| | وضع النموذج (الإعداد فارغ) | وضع الخادم (Supabase) |
|---|---|---|
| التخزين | متصفحك فقط | قاعدة بيانات Supabase، يراها كل الزوار |
| تسجيل الدخول | أي كلمة مرور، والدور يُختار يدوياً | حسابات حقيقية: أول حساب = المالك، والباقي بدعوة فقط |
| الصلاحيات | في الواجهة | يفرضها الخادم (Row Level Security) |
| الوسائط | تُصغَّر وتُحفظ في المتصفح | تُرفع إلى Storage بعد تحويل الصور إلى WebP |
| الطلبات والمرفقات | محلية | جدول `leads` وحاوية خاصة `lead-files` مع حد للإرسال |
| النشر والإصدارات | محلية | دالتا `publish` و `restore_version` على الخادم |

خطوات الربط في [`docs/SUPABASE_SETUP.md`](../docs/SUPABASE_SETUP.md).

في وضع الخادم تبقى التعديلات غير المحفوظة والمعاينة المباشرة في متصفحك. إذا حفظ مستخدم آخر مسودة
أحدث، تُحمَّل تلقائياً عندما لا تكون لديك تعديلات غير محفوظة. وإن كانت لديك تعديلات، تُسأل قبل
الحفظ: تحميل الأحدث أو الاستبدال بتعديلاتك.

**ما يزال تجريبياً في الوضعين:** المساعد الذكي يطابق الأوامر محلياً (الربط بـ Claude مرحلة لاحقة)،
والفيديو المرفوع في وضع النموذج يُعاين في الجلسة فقط.

## التحقق

جُرّب اختبار القبول كاملاً آلياً في المتصفح (Chromium): تسجيل الدخول ← تغيير اللون والخط وصورة
وفيديو ونص الواجهة ← إضافة مشروع ومعرض صور وترتيب ← إضافة عضو وخدمة ورأي ← تعديل القائمة والتذييل ←
حفظ مسودة ← معاينة ← نشر ← التحقق من ظهور كل التغييرات في `index.html` ← استعادة الإصدار v3 ونشره ←
عودة الموقع لحالته الأصلية. النتيجة 20/20 بدون أخطاء في الصفحتين، مع فحص الجوال (390px) والوضع الداكن.

**قواعد الخادم:** `python supabase/tests/test_rules.py` يشغّل كل قاعدة صلاحيات على Postgres
(يحتاج خادم Postgres محلياً؛ انظر رأس الملف).

**وضع الخادم كاملاً:** `supabase/tests/dev_stack.py` يشغّل الموقع مع PostgREST الحقيقي وبدائل محلية
لخدمتي الدخول والملفات. جُرّب عليه في المتصفح: إنشاء حساب المالك، النشر، رؤية الزائر للمحتوى
والصور من الخادم، نموذج التواصل مع مرفق، الدعوات، رفض التسجيل بلا دعوة، منع المحرر من النشر حتى
عبر الاتصال المباشر بالخادم، تعارض المسودات، والاستعادة.
